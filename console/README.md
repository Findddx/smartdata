# SmartData Operations Console

中文优先的企业数据工作空间。连接来源、盘点资产、核对发现，组织运维、分析和决策助手
与员工推进任务；原订单履约界面保留在“履约异常处理”专项入口。

开发与构建要求 Node.js 24 或更高版本；版本下限与 Vite 8 工具链保持一致。

## 本地运行

```bash
npm ci
npm run dev
```

开发服务器把同源 `/api` 请求代理至 `SMARTDATA_API_ORIGIN`，默认是 `http://127.0.0.1:8080`。
新工作区始终请求真实本机 API；不可用时明确报错，不替换成演示结果。电商样例需要用户
显式加载，且不能与用户来源混在一起。默认助手按规则整理证据；启用模型后按消息显示
模型方式、版本、引用、未知项与失败，不能直接执行业务动作。

旧履约专项保留原开发回退行为并明确标注；生产构建默认关闭，只有显式设置
`VITE_ENABLE_MOCK_FALLBACK=true` 才启用。该样板也必须人工批准、显式执行和独立验证。

## 质量检查

```bash
npm test
npm run build
```

前端不存储认证令牌，也不接受任意 API Origin。浏览器请求固定为同源 `/api/v1`，由服务器会话或安全网关处理身份。

本机工作区使用明确标注的演示身份，尚不是企业认证。产品操作见[上手指南](../docs/operations/workspace-quickstart.md)，
真实浏览器验收见[e2e 操作说明](e2e/README.md)。

开发服务器自动启用演练身份。生产构建若要用于本机演示，须在构建时显式设置
`VITE_DEMO_AUTH=true`；否则新工作区不显示身份切换，使用本机 API 默认的订单专员。
这个布尔旗标不是密码，也不能在生产 API 上建立权限。
