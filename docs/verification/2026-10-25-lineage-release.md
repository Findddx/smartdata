# 数据分层、血缘与远端合成实验：本轮验收记录

本轮让产品能够区分“盘点真正看到了什么”“业务人员登记了什么来源关系”和
“以后计划怎样使用结果”。新图没有自动提取真实客户、计算企业收入或执行经营决策。

## 已实现的产品行为

| 用户看到什么 | 实际依据 |
|---|---|
| L0 来源、表和字段 | 当前成功盘点的元数据；实线只表示物理包含，不表示已知道转换公式 |
| L1 业务实体定义 | 管理员明确登记输入字段和说明；虚线，仍未生成实体记录 |
| L2 指标定义 | 复用业务约定中的同一个指标编号和版本；声明来源，未计算数值 |
| L3 决策计划 | 明确登记指标与业务目标的关系；点线，未执行动作或证明业务效果 |

`METADATA_VISIBLE` 表示当前身份可看工作区元数据，不代表已获得来源读写或执行权限。
敏感程度未登记时显示未知，不按字段名猜测。观察是否过期单独显示；观察仍在有效
窗口内，也不能证明表里的所有业务记录都新鲜。

来源重配或盘点失败时只保留来源登记节点；不会把旧字段继续画成当前观察。已断开
的来源及依赖它的派生链不展示。管理员写映射时同时核对工作区与映射版本，指标还须
匹配已有口径版本；依赖类型只向更高层，不允许倒向或循环。处理说明不作为脚本执行。

默认图最多3000节点、6000边，最多显示256个字段。覆盖说明显示已展示/已登记数量；
不完整时明确提示，缺线不代表没有依赖。单表字段支持每页最多128项、带工作区版本的
分页；保存映射直接核对真实元数据，默认图未显示的合法字段仍可选择。缺少完整输入
的派生节点不会被画成完整链路。

新后端已在授权远端节点通过 **131项普通工程测试，0失败、0错误、0跳过**；其中
7项为本轮血缘回归，已经包含在131项中，不能重复相加。这7项覆盖真实元数据与
声明区分、未物化、方向、管理员权限、租户、范围、撤权、版本和分页预算边界。
最小超预算夹具是4张表各128字段：默认图明确显示256/512，预算之外字段仍可合法
登记和分页查看，其派生节点被隐藏时没有悬空连线。

构建使用官方字节已核验的 Temurin 25.0.4.1+1；依赖校验保持严格，没有增加接受的

记录各模块数量、源码包、补充公开领域包夹具和可运行 jar 的文件指纹。

## 真实接口与进程重启

增强后的[HTTP 冒烟脚本](../../contracts/scripts/smoke-workspace.mjs)也已在节点独立
工作区实际通过。HTTP 是这里前后端交换请求的通信协议，冒烟检查验证关键流程能否
连起来；本次不拦截接口、不替换返回，也没有触碰浏览器验收的工作区。

脚本从空工作区上传明确标注的合成快照，检查真实图与字段结构，登记输入映射，验证
只读拒绝、防重复、旧版本冲突、旧指标定义失效和范围收窄后的字段404。首次运行
到工作区版本15；实际停止进程并另起进程后，版本仍为15，映射、四版业务约定、
历史绑定及唯一一次映射保存审计均保留。定义始终未被冒充成已计算产物。

两阶段使用前述同一 jar、Temurin 25.0.4.1+1与 Node.js 24.17.0。实跑脚本 SHA-256为
`fb0c1682e391ddf258488d20bdb4ec4a8bc70b7e6524c35b62e04cefad12969c`。
临时进程均按身份核对后停止，已有预览与其他节点任务未受影响。这是本机模式的
真实网络与持久化检查，不证明已完成企业登录或外部凭据撤销。

## 仍需分别验收的事项

本轮普通测试与节点实验不代替真实浏览器操作、云端 CI 或客户试点。浏览器的登记、
保存、重新读取、聚焦和撤权体验由前端验收另记；新的 PostgreSQL 派生镜像及20项容器
回归由独立记录负责，不能借用本轮131项普通测试宣称通过。

目前仍是本地部署模式的元数据与协作能力。生产身份、细粒度授权、真实源系统 SQL
采集、执行作业与产物导入、容量与延迟目标仍须各自实现和实测。合成实验使用远端
CPU，并未使用 GPU 加速，也不证明真实企业收益或商业生产可用。
