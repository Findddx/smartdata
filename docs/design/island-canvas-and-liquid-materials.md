# 紧凑岛屿工作面与液态材质

状态：2026-10-25，按用户最新反馈实施；设计尚未验收。旧版硬分栏与分层竖列不再作为视觉终稿。

## 这一版围绕什么

视觉主线：石墨与矿物纸面的自由工作室，紧凑的岛屿承载真实工作，少量透明折射建立空间层次。
内容顺序：导航确定工作范围，画布解释数据依赖，伴随面板展示来源与限制；任务和表单继续保留清晰的阅读面。
交互主线：空间平移和聚焦帮助沿关系阅读；选中链路可演示方向；玻璃边缘回应位置变化，证据与文字保持稳定。

## 布局实际改变

- 导航、主工作面与说明面板各是独立表面，桌面间距约6–10像素，不再用贯穿页面的分割线。
- 统一圆角、控件高度、边缘光和阴影规则；工具带尽量薄，不把每个按钮都装成一个大浮岛。
- 图谱取消四条全高竖列。布局由真实输入与依赖决定，业务层级通过颜色、类型形状和浮动图例表达。
- 默认字号优先保证能读，缩到全图由用户主动选择。展开原始结构、字段与细节时说明当前覆盖范围，不补画聚合关系。
- 说明面板是伴随的工作岛；手机改为可到达的详情面，不把三列压缩到一屏。

VS Code 的[最新官方设计说明](https://code.visualstudio.com/blogs/2026/10/15/modern-ui)
及[主题实现约定](https://github.com/microsoft/vscode/blob/4ef6bab74bc303c46e8311904c6400b1a31ce761/src/vs/workbench/contrib/modernUI/README.md)
是布局与一致性的参考。它自身的磨砂浮层不等于本项目所需的液态折射，两部分分别核验。
只研究其设计和工程方法，不复制品牌、产品截图或把它作为运行依赖。

## 配色从原创艺术素材出发

主操作从普鲁士蓝开始，环境使用矿白与石墨。可扩展冷矿白、深石墨、暖朱砂与水碧等主题，
每套主题控制主色数量；不照搬米色加橙色的 Claude 视觉，也不使用蓝紫霓虹。

数据层级的蓝、朱红、灰绿、古铜继续承担固定含义；它们与主题主操作色分别管理。
艺术贴图营造环境，不铺在证据正文后面。节点的敏感程度、权限和新鲜度仍用独立标签解释。

## 材质与动效的边界

“真实折射”在这里指根据表面形状对背景像素产生可观察的位移，仍是网页中的光学近似，
不是物理仿真。不能仅凭透明色、模糊和一圈白边就称为液态玻璃。

候选实现须检查精确版本、许可证、源代码、浏览器实际表现、包体和释放资源的方式。
优先把折射限制在浮动工具、导航与说明面板的装饰层；文字、表单、节点位置和证据不扭曲。
不把业务 DOM 截图发送到服务端，不因效果不支持而阻止工作；强制高对比、减少透明度和减少
动画时都有普通表面或静态替代。各浏览器的真实折射与降级分别记录，不宣称完全一致。

粒子或光点只在用户追踪的已有关系上演示方向；它们不能暗示扫描、计算或业务动作正在执行。
观察、声明、计划的实线/虚线/点线仍保留。没有来源的“数据流”不会为了画面热闹而出现。

## 怎样验收

目前已采用固定提交的 [gentpan 光学核心](../../console/src/materials/README.md)，保留MIT
完整许可与修改说明；没有引入其组件库、壁纸或截图工具。热门 rdev 实现也重新核对过，
但其当前版本仍有浏览器位移限制；较新的 React 与 WebGPU 方案在依赖、包体和场景
捕获方面各有取舍，没有按星数宣布某个库“最好”。

三类真实浏览器内核已完成[已知图像的像素对照](../verification/2026-10-25-material-optics.json)：
只改变折射强度，边缘变化、中央不变，正文位置不变，强度0退回实体表面。
Chromium验证实时背景，Firefox/WebKit验证受控本地图像，两者不混写成任意业务DOM
都可跨浏览器折射。该小样检查可用[同一个脚本](../../console/e2e/material-optics.browser.js)
复现；它还不是整页帧率或真实iPhone证明。

检查1440与1920桌面、390宽真触摸浏览器、三类身份和主题；岛间空隙不挤占主要内容，
字号与点击目标清楚，面板可收放，表单与历史不丢失。实际验证玻璃的背景位移，不能只读配置名。
再次跑映射保存、并发冲突与草稿保护、字段分页和只读拒绝；减少动画时关系仍能理解。
记录普通与启用效果时的浏览器表现，源码构建、功能检查和用户审美验收分别给结论。
