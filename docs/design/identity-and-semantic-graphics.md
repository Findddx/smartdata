# 原创标识、艺术素材与图谱视觉约定

状态：本轮设计草案，用户尚未验收。参考仓库与方法保留，不提前固化为正式技能。

## 这版视觉围绕什么

工作面采用清浅灰白、墨色与克制的主操作色。布局像日常桌面工具，主画布承担数据
关系，次级面板解释当前对象，导航保持轻。光影只建立空间层次；艺术图不替代业务信息。

标识是本项目编写的折层与通道几何，表达各自有来源的信息形成共同路径。
[标识与图标研究页](../../console/public/brand/brandboard.html) 展示了 16、24、32 等尺度与深浅表面。
SVG 是可缩放的矢量图，类型图标使用相同描边、圆角与坐标体系；通用实体用对象形状，
明确的客户画像才使用人物图标，不把商品或供应商都画成人。

桌面初次查看图谱保留100%阅读比例，允许平移；只有主动选择“适应画布”才缩到
全图。图谱说明面板与原始证据互相链接，不把小到读不清的缩略图当作默认工作面。
窄屏提供分层跳转、列表和触摸操作。[实际空工作区](../images/lineage-empty.png)
使用艺术图，但不会自动填入演示数据。

## 视觉含义分开管理

| 视觉信息 | 稳定含义 | 不额外推断什么 |
|---|---|---|
| 蓝、朱红、灰绿、古铜 | 原始、实体、分析、决策四层 | 不直接表示风险高低 |
| 图标与节点形状 | 来源、表、字段、实体、指标、计划 | 不代表已经生成实体或计算指标 |
| 箭头 | 输入到结果的依赖方向 | 不为排版强行让每条路径逐层经过 |
| 实线、虚线、点线 | 观察、声明、规划的依据性质 | 声明不能当作采集到了源系统真实加工过程 |
| 独立标签与文字 | 权限、敏感程度、新鲜度、是否生成 | 未知必须显示未知，不只靠颜色传递 |
| 聚焦与收放动画 | 当前选择、上游下游与说明面板的空间关系 | 不假装任务有进展，不妨碍阅读或点击 |

图谱先在服务端限制显示规模，并给覆盖说明；字段按需加载。默认折叠字段不等于
可以先传输十几万个节点。局部影响分析必须带“当前视图不完整”的限制。

## 艺术素材怎样进入产品

内置 imagegen 生成了两张原创抽象习作：折层空间与观察几何。第一次网络调用返回
403，稍后通过同一个内置工具重试成功，没有切到备用 API 或其他供应商。

| 文件 | 网页副本大小 | 适用位置 |
|---|---|---|
| [折层空间](../../console/public/art/strata-study-v1.webp) | 约 365KB | 欢迎与无来源的空状态 |
| [观察习作](../../console/public/art/observation-study-v1.webp) | 约 278KB | 小幅使用指南或次级空状态 |

图中没有企业数据、文字或品牌。原始 PNG 保留本地；网页副本仅做格式压缩，尺寸与
构图保持一致。延迟加载，不铺到真实关系图和证据文字后面。
完整提示词、来源、原件与副本散列在[资产清单](../../console/public/art/art-manifest.json)。

手写 SVG 与真实生图分别记录，不能互相冒充。设计是否足够好看、好用，仍需在
实际产品中由用户判断；自动测试只能检验已覆盖的行为。
